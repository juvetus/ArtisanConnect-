# Plan réseaux sociaux - Lancement ArtisanConnect au Cameroun

## 1. Objectif

Faire connaître ArtisanConnect auprès de deux publics :

- les artisans qui doivent créer un compte et publier leurs produits ou services ;
- les clients qui doivent trouver un artisan et demander un devis.

La communication doit rester simple, locale et pratique. Le message principal n'est pas « découvrez une nouvelle technologie », mais :

> Trouvez un artisan près de chez vous ou présentez votre activité à de nouveaux clients.

## 2. Comptes à créer en priorité

### Priorité 1 : Facebook

Public large au Cameroun, artisans, familles, associations et petites entreprises.

Nom recommandé : `ArtisanConnect Cameroun`

Description proposée :

> Trouvez un artisan au Cameroun ou présentez vos produits et services à de nouveaux clients. Produits locaux, services, demandes de devis et contact WhatsApp.

Lien : `https://artisanconnectcm.info`

Actions :

- créer une page professionnelle ;
- ajouter le logo et une couverture avec des artisans camerounais ;
- publier dans les groupes locaux avec autorisation ;
- utiliser Facebook pour les campagnes par ville et métier.

### Priorité 2 : WhatsApp Business

Canal essentiel pour les artisans et les clients qui préfèrent échanger directement.

À préparer :

- profil professionnel ;
- description courte ;
- lien vers le site ;
- message d'accueil automatique ;
- réponses rapides ;
- catalogue avec les principaux parcours.

Message d'accueil :

> Bonjour et bienvenue sur ArtisanConnect. Cherchez-vous un artisan près de chez vous ou souhaitez-vous inscrire votre activité ? Répondez « TROUVER » ou « INSCRIRE ».

Réponse « TROUVER » :

> Indiquez votre métier recherché et votre ville. Vous pouvez aussi chercher directement sur https://artisanconnectcm.info/trouver-un-artisan

Réponse « INSCRIRE » :

> Créez votre compte ici : https://artisanconnectcm.info/register. Nous pouvons vous aider à ajouter votre profil et vos premières annonces.

### Priorité 3 : TikTok

Utile pour montrer les gestes, les ateliers et les réalisations.

Nom recommandé : `ArtisanConnect Cameroun`

Types de vidéos :

- avant/après d'une réalisation ;
- courte présentation d'un artisan ;
- fabrication d'un produit ;
- visite d'un atelier ;
- conseil d'un artisan ;
- témoignage d'un premier client ;
- tutoriel pour créer son profil.

### Priorité 4 : Instagram

À utiliser pour les photos de qualité, les produits, les métiers et les stories.

Nom recommandé : `@artisanconnect.cm`

Rubriques :

- Artisans de la semaine ;
- Produit local ;
- Service de la semaine ;
- À Yaoundé ;
- À Douala ;
- Femme entrepreneure ;
- Coopérative ou GIC ;
- Comment demander un devis.

### Priorité 5 : LinkedIn

À utiliser pour les institutions, entreprises, hôtels, ONG, bailleurs et partenaires.

Nom recommandé : `ArtisanConnect Cameroun`

Contenus :

- résultats du pilote ;
- partenariats ;
- données agrégées ;
- inclusion économique ;
- Made in Cameroon ;
- opportunités pour les entreprises et donneurs d'ordre.

## 3. Profils à préparer

Chaque compte doit contenir :

- le même logo ;
- le même nom ;
- une courte description en français simple ;
- le lien officiel `https://artisanconnectcm.info` ;
- un numéro WhatsApp professionnel ;
- la ville de référence ;
- une adresse e-mail professionnelle ;
- une image de couverture cohérente.

Ne jamais publier les mots de passe dans un document public. Utiliser une adresse e-mail dédiée et activer la double authentification.

## 4. Les deux messages principaux

### Pour les clients

> Vous cherchez un artisan fiable près de chez vous ? Trouvez son profil, regardez ses réalisations et demandez gratuitement un devis sur ArtisanConnect.

### Pour les artisans

> Vous êtes artisan au Cameroun ? Présentez votre activité, vos produits et vos services à de nouveaux clients. Créez votre compte gratuitement sur ArtisanConnect.

## 5. Piliers de contenu

### Pilier 1 : Les artisans

Présenter une personne réelle : nom, métier, ville, savoir-faire et lien vers son profil.

### Pilier 2 : Les réalisations

Montrer des photos ou vidéos réelles avec l'accord de l'artisan.

### Pilier 3 : Le besoin client

Publier des contenus orientés problèmes : trouver un plombier, une couturière, un menuisier, un décorateur ou un réparateur.

### Pilier 4 : L'éducation numérique

Expliquer simplement :

- comment créer un compte ;
- comment publier une photo ;
- comment demander un devis ;
- comment contacter un artisan ;
- comment éviter les arnaques.

### Pilier 5 : La confiance

Présenter les profils contrôlés, les avis, les règles de contact et les conseils de paiement.

### Pilier 6 : Le Made in Cameroon

Valoriser les produits locaux, les métiers traditionnels, les femmes, les coopératives et les savoir-faire régionaux.

## 6. Calendrier de lancement sur 30 jours

### Semaine 1 : Préparer la présence

- créer Facebook, WhatsApp Business, TikTok, Instagram et LinkedIn ;
- publier les informations de base ;
- publier un post de présentation ;
- inviter les premiers contacts ;
- préparer 10 contenus à l'avance ;
- créer un tableau de suivi des messages et contacts.

### Semaine 2 : Présenter le service

Publier :

- qui est ArtisanConnect ;
- comment trouver un artisan ;
- comment inscrire son activité ;
- les villes couvertes ;
- les métiers recherchés ;
- une courte démonstration du site.

### Semaine 3 : Montrer les vrais artisans

- inscrire les premiers artisans avec leur accord ;
- publier 1 artisan par jour ;
- partager leur profil ;
- demander à chaque artisan de repartager sa publication ;
- publier les premières réalisations.

### Semaine 4 : Attirer les clients

- lancer des publications par besoin ;
- contacter les groupes locaux ;
- proposer de demander un devis gratuitement ;
- publier les premiers retours ;
- mesurer les visites, demandes et contacts.

## 7. Rythme de publication conseillé

### Facebook

- 4 publications par semaine ;
- stories presque tous les jours ;
- 1 campagne locale par semaine.

### WhatsApp Business

- statut 1 à 2 fois par jour ;
- réponse aux messages le jour même ;
- diffusion uniquement aux contacts ayant accepté de recevoir les messages.

### TikTok

- 3 vidéos par semaine ;
- vidéos de 15 à 45 secondes ;
- sous-titres simples et lieu indiqué.

### Instagram

- 3 publications par semaine ;
- stories régulières ;
- 1 carrousel métier ou produit par semaine.

### LinkedIn

- 1 à 2 publications par semaine ;
- résultats, partenariats et impact du pilote.

## 8. Exemples de publications

### Publication artisan

> Voici [Nom], artisan [métier] à [ville]. Il/elle propose [produit ou service]. Découvrez son profil et contactez-le/la sur ArtisanConnect : [lien]

### Publication client

> Besoin d'un menuisier, d'une couturière, d'un plombier ou d'un décorateur à [ville] ? Décrivez votre besoin et demandez un devis gratuitement : [lien]

### Publication inscription artisan

> Vous êtes artisan au Cameroun ? Vous pouvez présenter vos produits et services en ligne, recevoir des demandes et être trouvé par des clients de votre ville. Inscription gratuite : [lien]

### Publication Made in Cameroon

> Acheter local, c'est soutenir un savoir-faire, une famille et une économie. Découvrez les créations des artisans camerounais sur ArtisanConnect : [lien]

### Vidéo courte

> 20 secondes dans l'atelier de [Nom], artisan [métier] à [ville]. Pour demander un devis, cliquez sur le lien dans la bio.

## 9. Promotion terrain et digitale

- demander à chaque artisan de partager son profil ;
- utiliser les groupes WhatsApp de quartiers et associations avec accord des administrateurs ;
- collaborer avec des micro-influenceurs locaux ;
- contacter les hôtels, restaurants, agences événementielles et entreprises ;
- distribuer des affiches avec QR code dans les lieux partenaires ;
- organiser une journée de création de comptes avec les artisans ;
- publier les métiers demandés dans chaque ville.

## 10. Budget publicitaire initial

Commencer avec un petit budget et mesurer avant d'augmenter :

| Étape | Budget indicatif | Objectif |
|---|---:|---|
| Test local | 50 000 à 100 000 FCFA | Tester 2 villes et 3 messages |
| Pilote mensuel | 150 000 à 300 000 FCFA | Attirer artisans et clients |
| Campagne élargie | 500 000 FCFA et plus | Étendre aux villes et métiers prioritaires |

Répartir les campagnes entre :

- acquisition d'artisans ;
- acquisition de clients ;
- promotion de produits et services ;
- retargeting des visiteurs intéressés.

## 11. Indicateurs à suivre chaque semaine

- portée des publications ;
- visites du site depuis les réseaux ;
- clics WhatsApp ;
- comptes artisans créés ;
- profils complétés ;
- produits/services publiés ;
- demandes de devis ;
- nouveaux clients inscrits ;
- coût d'acquisition ;
- artisans ayant reçu au moins un contact.

L'indicateur principal du pilote est :

> nombre d'artisans ayant reçu une vraie demande ou un vrai contact client.

## 12. Règles de confiance et de sécurité

- demander l'autorisation avant de publier la photo ou le numéro d'un artisan ;
- ne jamais publier les mots de passe ;
- activer la double authentification des comptes sociaux ;
- ne pas promettre un nombre de ventes garanti ;
- identifier clairement les contenus sponsorisés ;
- utiliser des photos réelles ;
- supprimer rapidement un contenu signalé ou trompeur ;
- éviter les paiements ou collectes non vérifiés par message privé.

## 13. Résultat attendu après 30 jours

- 30 à 50 artisans actifs ;
- 100 à 200 produits ou services publiés ;
- une présence régulière sur Facebook et WhatsApp Business ;
- les premiers contacts clients ;
- des témoignages et contenus réels ;
- des données à présenter aux ministères et partenaires ;
- une base solide pour demander un financement du pilote.
